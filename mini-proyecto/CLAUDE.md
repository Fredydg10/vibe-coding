API REST simple para gestionar tareas personales. MVP con 3 endpoints.

## 👤 Sobre mí (Fredy)
- Nivel: Intermedio en Vibe Coding
- Editor: Windsurf
- Sistema: Windows (PowerShell)

## 🛠️ Stack
- Backend: Node.js + Express
- DB: Array en memoria
- Testing: Thunder Client

## 📋 Reglas de código
1. Usar const/let, nunca var
2. Funciones máximo 30 líneas
3. Nombres descriptivos en camelCase
4. Separar controllers y utils
5. Manejo de errores obligatorio
6. Comentarios en español
